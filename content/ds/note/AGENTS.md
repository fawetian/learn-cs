# note/ — 分布式系统学科的全部文章

- 放什么：长文笔记。单篇文章平铺为一个 `<topic>.mdx`；如果是专题研究（围绕同一主题的多篇系列文章），建子目录 `<topic>/` 存放，并在子目录里放 `index.mdx` 作为专题导读。
- frontmatter 必须含 `title` 和 `description`，否则网站构建会报错。
- 配图放 `../_asset/<topic>/`，文中用 `../_asset/<topic>/xxx.png` 引用。
- 不放什么：书籍资料（→ `_book/`）、收集的课程论文（→ `_resource/`）、渠道发布稿（→ `_publish/`）、思维导图（→ `_mindmap/`）。
- 这个目录会被网站收录成页面，写入时注意是公开内容；子目录在侧边栏里显示为一个分组。
